# Advanced Topics

This chapter covers advanced techniques and production deployment-related techniques for WebAssembly applications.

There will be no more exercises for this chapter. You're encouraged to read through this chapter and try experiment with the techniques described.
If you have time to spare, feel free to extend your calculator application: try a different storage backend, or swap the Spin SDK for [`wstd`](https://github.com/bytecodealliance/wstd) in one of the HTTP-only exercises and run it under `wasmtime serve`. Check out this chapter's [Outro](./XX_outro.md) for inspiration.
